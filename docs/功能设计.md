# 📖 安卓沉浸式 EPUB 阅读器 · 功能设计

> 版本：v1.0.4 · 本文档描述 App 的全部功能与交互设计，供功能理解、迭代与排查参考。
> 架构一句话：**Kotlin 原生壳 + WebView 内嵌网页阅读器（epub.js）**，原生层管系统能力（手势/沉浸/存储/文件选择），Web 层管书籍渲染与阅读交互。

---

## 1. 项目概览

| 项 | 值 |
|---|---|
| 用途 | 手机沉浸式 EPUB 电子书阅读器（纯读书，无自定义网页/设置） |
| 形态 | 单个 Activity + 全屏 WebView |
| 阅读器本体 | `app/src/main/assets/reader-bookshelf.html`（自带 `IS_NATIVE` 安卓适配层，桌面浏览器可直接打开同一文件） |
| 渲染引擎 | epub.js（分页模式 `flow: 'paginated'`）+ JSZip |
| 最低版本 | minSdk 29（Android 10）/ targetSdk 35 / compileSdk 35 |
| 屏幕适配 | edge-to-edge，内容延伸至系统栏区域 |

## 2. 系统架构

### 2.1 分层

```
┌────────────────────────────────────────────────────────────┐
│  Web 层  reader-bookshelf.html + epub.js                     │
│   书架 UI / 阅读器 UI / 目录 / 设置面板 / 主题注入 / 翻页逻辑   │
│   window.AndroidBridge ────────────┐                         │
├────────────────────────────────────┼────────────────────────┤
│  原生层  Kotlin                     │                         │
│  MainActivity        WebView/沉浸/返回/音量/生命周期           │
│  EpubBridge          JS 桥（导入/列表/删除/状态）              │
│  EpubStore           filesDir/epubs 内部存储，流式导入          │
│  EpubWebViewClient   WebViewAssetLoader 同源 URL              │
│  EpubWebChromeClient confirm/alert 原生弹窗                   │
│  ImmersiveController 系统栏隐藏/显示                           │
│  GestureController   单指/多指滑动与点击翻页识别                │
└────────────────────────────────────────────────────────────┘
```

### 2.2 关键数据流

- **书籍文件**：SAF 文件选择器 → `EpubStore.importFile` 流式拷入 `filesDir/epubs/` → 后续 WebView 经 `https://appassets.androidplatform.net/epubs/` 同源流式读取（**不整包进内存、不走 IndexedDB**）。
- **阅读器页面**：`WebViewAssetLoader` 以 `https://appassets.androidplatform.net/assets/reader-bookshelf.html` 加载，页面与书籍同源，规避跨源/fetch 不可靠问题。
- **JS↔原生**：JS 调 `AndroidBridge`（JavascriptInterface，运行在工作线程，需 post 回主线程）；原生调 `window.<fn>` 仅通过 `evaluateJavascript`。

## 3. 功能设计

### 3.1 书籍导入与存储

**交互**
- 书架底部「📂 打开EPUB」→ 系统文件选择器（SAF，可多选类型 `*/*`）→ 选中后自动导入并回书架。
- 导入过程有全屏 spinner 遮罩（无文字，纯转圈）。

**技术**
- 存储目录：`filesDir/epubs/`（App 私有，卸载即清）。
- **流式导入**：`contentResolver.openInputStream` 直接 `copyTo` 落盘，30–50MB 大文件不 OOM。
- 文件名清洗：非法字符替换为 `_`、去重（`name (2).epub`）、强制 `.epub` 后缀、限长 100 字符。
- **安全**：`resolveFile` 做 canonical 路径前缀校验，防路径穿越。
- 元数据（标题/作者/封面）首次导入时从 epub 包提取并存 `localStorage`，书架卡片直接读缓存不重复解析。

### 3.2 书架

**交互**
- 书架 = 网格卡片，每张卡片显示：封面 / 书名（截 20 字）/ 作者（截 15 字）/ 上次阅读进度（章节名 + `页/总页`）。
- 无封面时用**渐变 SVG 占位封面**（深色/浅色主题分别配色）。
- 卡片右上角 ✕ 删除（原生 `AlertDialog` 确认）；底部「🗑 删除」进入删除管理模式让 ✕ 常显（真机无 hover）。
- 排序：**最近打开的书排最前**（按 `lastOpened_<书>` 时间戳）。

**技术**
- `rebuildShelf()` 重建书架界面**不重载 WebView**（避免反复进出书架导致 WebView 内存累积崩溃）；重建时销毁旧 rendition/book、解除阅读锁定滚动。
- 深色模式下外层、卡片背景、占位封面配色同步切换。

### 3.3 阅读器渲染（epub.js）

**交互**
- 点卡片进入阅读器，正文分页渲染，单页/双页由布局模式决定。
- 打开书时全屏遮罩（spinner）→ 首屏就绪即快速消失（最多 400ms 硬顶）。

**技术**
- `book.renderTo(viewer, { flow: 'paginated', snap: true, allowScriptedContent: false })`。
- 分页模式锁定滚动：外层 `html`+`body` 同时内联 `overflow:hidden; height:100%`（部分 WebView 只锁 body 不生效，须双锁；返回书架时同步解锁）。
- **SVG 插图处理**：内容加载钩子（`rendition.hooks.content`）把 SVG `<image>` 替换为固定高度 `90vh` 的 `<img>` 占位，每张图独立一页、图片异步加载不影响布局，杜绝重排连跳；`object-fit:contain` 修椭圆。
- `ResizeObserver` 监听阅读区尺寸变化自动 `rendition.resize()`（侧栏收起/窗口缩放时重排）。

### 3.4 沉浸式阅读

**交互**
- **竖屏**：进入阅读自动隐藏顶部工具栏与底部控制栏（`chrome-hidden`），点屏幕**中间**唤出。
- **横屏/平板**：工具栏常显；同样可点中间切回沉浸。
- **旋转屏幕**：自动按新方向重置沉浸状态与默认布局（手动选过布局则保持手动选择）。
- 唤出工具栏时系统栏同步显示（状态栏紫色与工具栏同色）。

**技术**
- `ImmersiveController`：`WindowInsetsControllerCompat` 隐藏/显示系统栏，edge-to-edge。
- 工具栏/底栏显隐：CSS 类 `body.native-mode.chrome-hidden` 控制 `opacity` + `translateY` 过渡（0.2s）。
- `AndroidBridge.notifyMenuOpen` 通知原生下拉菜单开合状态，打开时禁用原生点击翻页/沉浸，防误操作。

### 3.5 翻页（核心）

**触发方式（全部可用）**

| 方式 | 动作 | 方向 |
|---|---|---|
| 单指快速横滑 | 左滑/右滑 | 下一页 / 上一页 |
| 单指中速/斜滑 | 水平位移主导（见阈值） | 同上 |
| **多指滑动**（双指/三指） | 任一手指横向滑动（手掌/其他手指静止不干扰） | 同上 |
| 边缘点击 | 左 1/3 / 右 1/3 屏幕 | 上一页 / 下一页 |
| 音量键 | 音量加 / 音量减 | 上一页 / 下一页 |
| 键盘（桌面） | ← / → | 上一页 / 下一页 |

**手势识别（GestureController）**
- 单指 fling 阈值：水平位移 ≥70px、水平 ≥1.5×垂直（斜滑容错）、X 向速度 ≥500、时长 ≤600ms、非长按。
- **多指**：一次手势中出现 ≥2 根指针即按多指处理——取**横向位移最大的手指**判定方向（静止手掌不干扰）；位移 ≥ 屏宽 10%（至少 100px）、水平 ≥1.5×垂直；多指手势不触发点击（防手掌误触）。
- 长按（>400ms）抑制 tap/fling，保留 WebView 内 epub 正文的原生长按选词。

**翻页执行（网页层，防止卡死/连跳的核心）**
- **串行任务队列**：`flipViewer` 入队，`processNextFlip` 逐页执行；队列限长 8（超长 shift 丢弃）、每任务 4s 超时兜底（epub.js 异常时强制释放，避免卡死）；任务间隙用 `requestAnimationFrame` 衔接贴近帧节奏。
- **直接 next/prev，不检测位置**：纯图片章翻页后 CFI/href 不变，位置检测会误判"没翻页"而自动重试 → 连跳。只在 epub.js promise reject（分页未就绪）时延迟重试，最多 2 次。
- **翻页路径最轻**：只调 `rendition.next()/prev()`；主题/字号重活按文档守卫执行（见 3.9），同章节翻页不重注入。
- **动画**：默认「无」= 瞬时切换最流畅；「淡入」= 先等新页渲染完成再 40ms 极短淡入（不先淡出，全程无空白/双闪）；「滑动」= 轻移 6% 提示 → 后台翻页 → 快速回正，`will-change` 仅动画期间开启。

### 3.6 阅读设置

**面板**：竖屏顶部按钮收进 ☰ 下拉菜单；横屏完整工具栏直显。

| 设置 | 选项 | 生效方式 |
|---|---|---|
| 字号 | A− / A+（12–32px） | `rendition.themes.fontSize` |
| 行距 | 紧凑 1.4 / 标准 1.8 / 宽松 2.2 | 主题 CSS 注入 |
| 页边距 | 窄 / 中 / 宽（viewer padding 10/30/50px） | CSS 类切换 + `rendition.resize` |
| 字体 | 默认 / 衬线 / 无衬线 | 主题 CSS 注入 |
| 亮度 | 30–100 滑块 | 屏幕叠加黑色遮罩模拟变暗（`pointer-events:none`，不挡触摸） |
| 背景色 | 白 / 浅绿 / 类纸 / 🎨自定义（8 色板 + RGB 滑块） | body 类 + 主题 CSS |
| 明暗主题 | 深色 / 浅色 | 外层 + iframe 内双份应用 |
| 翻页效果 | 无 / 淡入 / 滑动 | 见 3.5 |
| 单双页 | 单页居中 / 双页并排（窄屏双页自动退化为单页） | `rendition.spread` |

**自定义颜色**：色板点选或 RGB 滑块实时合成，存 `localStorage.customBgColor`。

### 3.7 目录导航

**交互**
- ☰ 打开左侧目录侧栏（章节标题来自 spine，`第 N 章` 自动加载真实标题补齐）。
- 点击章节跳转，跳转后侧栏自动收起并重排（阅读区宽度变化需 `rendition.resize`）。
- 目录侧栏打开时，点击正文区域先收起侧栏、不翻页（原生层 `handleTap` 分类处理）。

**技术**
- 目录点击与"点内容关目录"靠坐标判定：触摸坐标为**物理像素**，页面为**逻辑像素**，须除以 `devicePixelRatio` 换算。

### 3.8 阅读进度与恢复

**交互**
- 阅读时实时显示页码（`N / 总页`）与章节进度百分比；底部可拖动进度条跳章。
- 打开书后自动回到上次阅读的**同一页**（精确 CFI）。

**技术**
- 定位：优先 `rendition.display(CFI)`，分页未就绪时自动重试（≤3 次 ×350ms），失败回退到正确章节开头。
- 进度计算：多章书按章节比例，单章书按页码（避免进度恒为 0）。
- 进度保存节流：`localStorage` 写会阻塞主线程，至少间隔 1.5s 存一次（翻页热路径不写盘）。
- 章节切换：顶部标题合成「书名 + 章节名」单元素防换行；跨章节弹出章节名横幅（1.5s 自动消失）。
- **不生成 locations 全页索引**（省内存，降低 WebView 崩溃风险）。

### 3.9 主题与背景（CSS 注入）

**技术**
- 向 epub iframe 内注入 `<style class="app-theme">` 实现：背景色、文字色、链接色、行距、字体、隐藏滚动条、背景图 `background-size:contain` 防拉伸。
- **文档守卫**：`WeakMap doc→css`，同一章节翻页时 iframe 文档不变、主题未变 → 跳过注入（原实现每页重建 style 触发 iframe 重排，是翻页卡顿主因）；换章节/换主题才注入。
- 深色模式额外注入 `*{background-color:transparent!important}` 清掉书内自带黑底。
- **不改 epub 内容元素属性**（会破坏 epub.js 分页导致翻页连跳），插图比例全靠注入 CSS 修。

### 3.10 插图修复（SVG 插图书）

- 该书插图是 **SVG `<image>` 标签**（非 `<img>` 非 CSS 背景）。
- 修复链：`image{object-fit:contain;max-width:100%;height:auto}` + `*{background-size:contain}` + `aspect-ratio` 按 viewBox 比例 + hooks 替换为 `<img>` 占位。
- 每张插图独立一页（wrap 90vh），图片异步加载不影响布局 → 杜绝重排连跳。

### 3.11 返回键与系统键

- **阅读器内按返回** → 先回书架；JS 6s 无响应则兜底退出 App（`returnPending` 标记）。
- **书架按返回** → 退出 App。
- 音量键翻页固定开启（见 3.5）。
- `onPause/onResume` 暂停/恢复 WebView timers；`onTrimMemory(≥MODERATE)` 调 `webView.freeMemory()` 释放内存。

### 3.12 内存管理（贯穿性要求）

| 场景 | 措施 |
|---|---|
| 进出书架 | 重建界面不重载 WebView（`rebuildShelf`） |
| 打开新书 | 销毁旧 `rendition`/`book`、清空旧 viewer 内容 |
| 内存吃紧 | `onTrimMemory` → `webView.freeMemory()` |
| 进度定位 | 不生成 locations 全页索引（省内存） |
| 主题注入 | 文档守卫避免每页重建 style |
| 翻页 | 队列限长 + 超时兜底防 epub.js 卡死 |

## 4. 关键交互约定

1. 点屏幕左 1/3 = 上一页；右 1/3 = 下一页；中间 = 切换系统栏/工具栏（沉浸）。
2. 音量加 = 上一页；音量减 = 下一页。
3. 手势中一旦出现 ≥2 根手指，整次手势按"多指滑动"处理（不触发单指点击）。
4. 长按（>400ms）让位于原生文本选词。
5. 动画一律"无感"：淡入压到 0.04s、位移最小、去掉回弹回落。
6. 返回键优先级：阅读器 → 书架 → 退出。

## 6. JS 桥协议（window.AndroidBridge）

| 方法 | 方向 | 说明 |
|---|---|---|
| `bridgeVersion()` | JS→原生 | 返回 `"1.0"`，同时用作 `IS_NATIVE` 检测 |
| `importEpub()` | JS→原生 | 唤起 SAF 文件选择器 |
| `listEpubs()` | JS→原生 | 返回 JSON 数组 `[{name,size,timestamp}]` |
| `deleteEpub(name)` | JS→原生 | 返回 `{ok:true}` 或 `{ok:false,error}` |
| `notifyState(state)` | JS→原生 | `'shelf'`/`'reader'`，原生据此切换沉浸与返回键行为 |
| `notifyMenuOpen(open)` | JS→原生 | 下拉菜单开合，控制原生点击翻页是否禁用 |

原生→JS：统一 `evaluateJavascript("window.<fn> && window.<fn>(<json>)")`，数据走 JSON 字符串不拼装代码。

## 7. 关键技术决策

1. **书籍走内部存储 + 同源 URL，不用 IndexedDB**——跨会话丢失与容量限制风险；流式读取不整包进内存。
2. **HTML 单文件双跑**（`IS_NATIVE` 检测）——原生走桥，桌面浏览器保留 IndexedDB 路径，改一处两边生效。
3. **翻页不检测位置**——图片章 CFI 不变，检测会导致误判连跳；只对 promise 报错重试。
4. **翻页串行队列 + 限长 + 超时**——epub.js 不并发安全，防止连按卡死。
5. **主题注入文档守卫**——翻页性能的关键（同章节不重注入）。
6. **动画无感优先**——"流畅"= 瞬时/极短动画，不追求花哨过渡。
7. **内存优先**——少生成索引、少重载、主动释放。

## 8. 构建与交付

```bash
cd <项目根目录>
export JAVA_HOME=<JDK 17+ 安装目录>
sh ./gradlew assembleDebug --no-daemon
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

**交付约定**
- 每次改动**递增 versionName + versionCode**（否则手机"相同版本"不覆盖安装，用户看到旧版）。
- 复制为带版本号文件名 `EpubReader-vX.Y.apk` 供用户覆盖安装。
- **WebView 缓存是"改动不生效"的元凶**：App 已用 `LOAD_NO_CACHE` + `clearCache(true)`，但用户真机覆盖安装仍可能缓存旧 HTML；确认不了就卸载重装。书架标题显示版本号可快速确认。

## 9. 已知注意点与排查

| 现象 | 排查方向 |
|---|---|
| 改动"不生效" | 先查部署链路：版本号是否递增、WebView 缓存、是否需卸载重装（不要怀疑用户装错版本） |
| 翻页卡顿 | 是否每页重注入主题（应被文档守卫拦截）；软件渲染模拟器慢，真机为准 |
| 插图椭圆 | SVG `<image>` 需 object-fit + background-size + aspect-ratio 组合；真机安卓 16 上 object-fit 对 SVG image 可能不生效 |
| 手势不翻页/滚动条 | 检查 html+body 双锁是否生效、WebView 滚动条是否禁用、手势是否满足阈值（斜滑容错 1.5×） |
| 删除执行不了 | `EpubWebChromeClient` 必须实现 `onJsConfirm`，否则 confirm 恒 false |
| 模拟器黑屏 | `emulator -avd <名> -gpu swiftshader_indirect` 软件渲染重启 |
| 模拟器测试手势 | `adb emu finger` 是"指纹传感器"不是触摸屏；多指注入不可靠，多指功能靠真机验证 |
